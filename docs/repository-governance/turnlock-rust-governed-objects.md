# Turnlock-Rust Governed Objects profile

This consumer-owned profile enumerates the initial generic governed-object
surface adopted by Turnlock-Rust. The immutable contract pin identifies only
the proto-ring representation contract; Turnlock-Rust authority remains in the
sources mapped by the Governance Authority profile.

The catalog intentionally contains no invariant statements, ADR decision
bodies, or generic ADR relations. Existing ADR-specific contracts continue to
own ADR relations. Historical ADR records remain cataloged without making their
superseded decisions active authority.

This profile does not establish catalog currentness and does not create a
validation, evidence, or projection registry.
